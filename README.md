국내 여행지 추천 프로그램

여행 날짜를 입력하면 AI가 그 시기에 어울리는 국내 여행지를 추천해주고, 그 지역 맛집까지 찾아서 여행 리포트로 정리해주는 프로그램을 만들었습니다.

LLM API와 지도 API, 두 개를 이어붙여서 하나의 흐름으로 만드는 게 이번 과제의 핵심이었는데, 저는 Gemini API와 Kakao Local API 조합으로 구현했습니다.

<br>

프로그램 개요

이 프로그램은 단순히 API 하나만 호출하는 게 아니라, 이전 단계의 결과가 다음 단계의 입력이 되는 구조로 짰습니다.

1차 추천 (Gemini API) 입력받은 날짜를 Gemini에게 보내서, 그 시기에 여행하기 좋은 지역·날씨·행사 정보를 JSON으로 받습니다.
맛집 검색 (Kakao Local API) 1단계에서 받은 지역명을 그대로 카카오 로컬 API에 검색어로 넘겨서 맛집 5곳을 찾습니다.
최종 리포트 생성 (Gemini API) 1, 2단계 결과를 다시 Gemini에게 넘겨서 하나의 여행 리포트(Markdown)로 종합합니다.
결과 저장 results/ 폴더에 원본 데이터(JSON)와 리포트(Markdown)를 각각 저장합니다.
<br>


실행 환경
Python 3.10 이상에서 작업했습니다.
VSCode 터미널에서 CLI로 실행하는 방식으로 만들었습니다.

<br>

실행 방법
1. 패키지 설치

먼저 필요한 패키지를 설치합니다.

bash
pip install -r requirements.txt

2. API 키 설정

프로젝트 폴더에 .env 파일을 만들고, 아래 형식으로 본인이 발급받은 키를 넣으면 됩니다.

GEMINI_API_KEY=발급받은 Gemini 키
KAKAO_REST_API_KEY=발급받은 Kakao REST API 키

저는 아래 순서로 키를 발급받아서 사용했습니다.

Gemini API 키: https://aistudio.google.com 에서 "Get API Key"로 발급
Kakao REST API 키: https://developers.kakao.com 에서 애플리케이션 생성 후 "앱 키" 메뉴에서 REST API 키 확인

작업하면서 카카오 쪽에서 403 오류가 났었는데, 앱 설정의 "제품 설정 → 카카오맵"이 기본적으로 비활성화되어 있어서 그런 거였습니다. 이 부분을 활성화해야 정상적으로 검색이 됩니다.

3. 실행
bash
python travel_planner.py --date "2026-03-15"

--date는 필수 옵션이고, YYYY-MM-DD 형식이 아니면 오류 메시지를 출력하고 종료되도록 만들었습니다.

실행하면 아래처럼 단계별 진행 로그가 뜹니다.

[1/3] 1차 추천 생성 중(LLM)...
   - recommended_city: "전남 광양"
[2/3] 맛집 검색 중(지도/장소 API)...
   - 맛집 5곳 검색 완료
[3/3] 최종 리포트 생성 중(LLM)...
   - 리포트 생성 완료


완료! results/2026-03-15_travel_plan.md 를 확인하세요.

<br>



결과물 확인 방법


실행이 끝나면 results/ 폴더가 자동으로 생기고, 그 안에 파일 두 개가 저장됩니다.

{날짜}_data.json 1차 추천 결과, 맛집 검색 결과, 오류 요약을 함께 담은 원본 데이터입니다.

{날짜}_travel_plan.md 추천 지역, 추천 이유, 날씨, 행사·축제, 맛집 리스트, 1일 일정 제안, 오류 요약까지 들어간 최종 리포트입니다.
<br>

에러 처리는 이렇게 했습니다
API 키가 설정되어 있지 않으면 프로그램을 바로 종료시키고, .env 설정 방법을 안내하도록 만들었습니다.
카카오 API 호출이 실패하거나(인증 오류 등) 검색 결과가 0건이어도 프로그램이 멈추지 않고, 맛집 섹션을 "데이터 없음"으로 처리한 뒤 리포트 생성 단계로 계속 넘어가도록 했습니다.
Gemini 응답이 JSON으로 파싱되지 않을 경우엔, "필수 키만 다시 JSON으로 출력해달라"는 프롬프트로 한 번 더 요청하도록 했습니다. 그래도 실패하면 오류로 기록하고 넘어갑니다.
이렇게 발생한 오류들은 전부 errors 리스트에 모아서, 원본 JSON과 최종 리포트의 "오류 요약" 섹션에 같이 남도록 했습니다. 오류가 없으면 빈 리스트로 남습니다.
<br>
API 키 보안

API 키는 코드 안에 직접 쓰지 않고, .env 파일에 넣어서 관리했습니다.
.env는 .gitignore에 등록해서 깃허브에 올라가지 않도록 했습니다. (저장소 파일 목록에서도 확인하실 수 있습니다)
그래서 이 저장소를 클론해서 실행하려면 .env 파일을 본인 키로 새로 만들어야 합니다.
작업 중 카카오 키가 화면 캡처에 잠깐 노출된 적이 있어서, 작업 마무리하면서 키를 재발급받아 교체했습니다.
